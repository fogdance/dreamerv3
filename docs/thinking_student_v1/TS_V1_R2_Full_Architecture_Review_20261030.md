# Thinking Student V1：完整 1x-R2 与「经济价值优先、执行质量其次」架构综合 Review

日期：2026-10-30  
依据：`R2_1X_FULL_20261030.md`、此前 E0/E1/E2/E3、1x/10x、SL5/MAE 实验以及 `TS_V1_Brain_Architecture_PreReview_20261030.md`。本文区分**报告事实**与**待验证的机制假设**，不宣称在本轮重新执行了源码测试。

## 1. 总结与判断

- **工程闭环通过**：完整 R2-1x 的 9 轮 `CF → R2 重标注 → S5 → L6/L2 → L4 → L5 → freeze → DEV` 全部成功；同一 π0/foundation、相同金融规则与训练预算，R2 标签财务恒等核验通过。
- **完整 R2 没有建立选点改善**：π1–π9 平均 DEV PnL 原 1x −28,054 元、R2 −27,189 元；平均仅改善 865 元。同频随机超额 PnL 原 1x 平均 −636，R2 −4,659；R2 0/9 轮优于同频随机（仅 5 随机种子，且 DEV 已用于迭代分析，不推断统计显著性）。
- **E2/E3 的局部收益具有路径依赖**：从 R0 π6 分叉 R2 可让 π7/π9 少交易、少亏；从 π0 全程 R2 则并未稳定保持，π9 R2 275 次 ADD / −29,550 元，相对原 1x π9 的 268 次 / −25,764 元没有改善。
- **R2 经济目标本身是有解释性的**：全程 2760 市场分钟内归一化净盈亏、无折扣；EXACT_STATE 全部经济持平是严格经济等价结果，不是标签 Bug。R2 并未修改原 Native Reward、分级老师和 Outcome 目标，因此并非“全大脑经济目标已经统一”。
- **优先研究的是 Q 的可学习性及跨策略传递**，而不是继续调止损、加 10x、删零标签或先改 κ。当前 πk 的 Q 用旧 π 的 CF 训练，却要用于已变更的 πk 行为；即便符合策略迭代原理，样本外条件价值随着政策更新而改变，必须区分“同策略也学不会”和“同策略学会但跨策略失效”。

关键分歧：R2 π3 ADD=33、PnL=−1,194，κ=0.132，Anchor 阻止 ADD 5,976 次。对应第 3 轮 CF 79.3% 为 EXACT_STATE/经济持平；第 4 轮持平降至 9.5%，κ 回到 0.454，π4 ADD=268。这说明观察到的是**依赖合约/轮次的强烈波动**，不是必然单调退化成 WAIT。不能以 κ 下降单独解释因果，必须同时看原始 ΔQ 的正负/幅度、Correction、合约分布。

Q 的符号偏好与真实非持平 CF 明显失配：π3 的预测偏好 ADD 比例 2%，实际已完成非持平 CF 中 ADD 更好的比例 76%，符号准确率 22.2%；π5 的预测偏好 ADD 89%，实际 ADD 更好 35%，准确率 41.3%。这些样本并非全部合法机会；CF 闭合并非随机，不能据此估计市场全体机会的好坏比例。

## 3. 六个脑区的任务是否统一？

| 结构 | 已知训练任务 | 在“双层目标”中的位置 | 待检验 |
|---|---|---|---|
| Market Brain / Account Encoder / Fusion | 因果市场与账户表征；L1、部分 L2 表征适配 | 经济/执行预测共同输入 | 是否保留预测 ΔG 的足够信息；市场/合约分布差异 |
| Outcome Brain | TP/SL、MAE/MFE、退出时间和 Quality | **执行质量**证据，也可估计单笔经济收益 | E0 样本外 pSL AUC 接近 0.5，质量能否更稳定预测？ |
| Value Brain | Q_WAIT/Q_ADD 与 ΔG，L4 只更新 Value | **经济价值主判断**，且 Q 是冻结策略条件的多步回报，不是单笔 ADD 盈利率 | 同策略能否学到非持平 ΔG？跨策略有多大漂移？ |
| Intuition/Reasoning/Gate | L3/L5 分级老师示范，使用 SG(Outcome/Q) | 提供行为先验与质量偏好 | 纠正价值错误，还是压过正确价值？ |
| Final Actor | `z=correction+β clip(ΔQ/κ,±3)`，合法 mask | 最终选择 WAIT/ADD | 加法融合是否将未经校准的 Q 偏差放大？ |
| Native / CF / S5 | 真实交易后果、固定策略反事实与教学反馈 | 正确的学习事实供应链 | 非零资金差 CF 更难得到完整标签，零标签占比高 |

**关键概念**：`Q^π(s,ADD)−Q^π(s,WAIT)` 比较的是“现在 ADD 后遵守 π”与“现在 WAIT 后遵守 π”的完整未来经济差异。WAIT 不等于永远不交易；不能用“这笔入场最终 TP 的概率”替代这个价值差。

## 4. 经济价值优先，执行质量其次：建议的目标分层

**层 1 经济可行性**：在当下可观察因果状态下，预测 `ADD` 相比 `WAIT` 的未来净经济差异（考虑手续费、SL30和后续机会）。主 Q 保留 R2 的经济解释，不把 Quality 的快/慢偏好直接覆盖真实净收益。

**层 2 执行质量**：对经济上相近的备选，比较首次交易 TP/SL、MAE/MFE、退出时长、资金占用和可解释的风险。若 Q 真实差异为 0，执行质量仍可使提前退出、逆行较小的机会优先；这应是明确次目标，不应把经济负优势误判为“快所以值得开仓”。

**层 3 先验与执行**：老师示范是训练时可用的行为先验，不是天生正确的经济真值。Final Actor 需要检验与经济 Q 发生冲突时的真实结果。**但在 Q 尚无泛化能力前，不应立即将其提升为硬经济 Gate，也不应为获得交易次数强行 ADD。**

这是一项研究设计选择，不是建议在现阶段立即改写网络为两层 Gate。首先验证不同层次的预测在独立留出数据上是否存在。

## 5. 核心机制假设（按证据强度）

1. **证实：目标与学习能力不同。** R0 的 Quality/折扣目标和 R2 净经济目标不同；完整 R2 数值核对正确，但 Q 仍没有可靠价值排序。优化目标改正不等于函数逼近器能学会。
2. **证实：R2 下大量持平标签有经济解释。** 每轮 EXACT_STATE 的 ΔG=0，持平占比主要随合约/耦合类型变化；不应删除全部零标签。
3. **证实：Q 的动作偏置跨轮次剧烈变化。** π3 2% 预测 ADD vs 76% ADD 更好；π5 89% vs 35%；β Anchor 跨轮次有益有害交替。
4. **待验：L4 监督中非零信息有限且有选择偏差。** FUNDS_SAFE 或其他无法快速 EXACT 的路径更可能有非零差额，但非零资金差的 CF 更难完整闭合。
5. **待验：策略版本滞后影响 Q 泛化。** πk 的当前行为不同于产生其训练 CF 的 πk−1，`Q^π`的条件目标随 π 变化；这是策略迭代可预期的困难，不是自动认定为代码 Bug。此前 10x 在固定一批 CF 的留出集优于常数，却未跨轮迁移，值得隔离测试。
6. **待验：L4 冻结 Market/Fusion 与 L5 仅训练 Correction，使经济信息无法端到端协调。** 先测是否存在可预测性，再考虑调整梯度或损失。
7. **当前不支持：宣布市场无信号。** E0 Outcome 和 20 因子探针在独立合约上接近随机，说明现有实验未找到稳健信号，不构成不存在经济可预测信息的证明。

## 6. 下一步推荐：E4，一次可解释的价值可学习性实验

不要再完整跑 1x/10x 来猜。固定单一冻结策略 π 与其 CF，保持目标/数据版本一致，做以下最小受控研究：

**E4-A 同策略、真正留出**
- 对同一策略的 R2 CF，按时间连续块与合约做隔离训练/评价；统计 EXACT_STATE=0 与非零样本的数量、方向、大小及覆盖。
- 比较零预测、按合约常数/多数方向、简单 Ridge/GBDT、现有冻结 Fusion+Value 与可能的原始因果市场特征。所有模型仅使用决策前信息，拆分与标准化只能用训练折。
- 同时报两套指标：①在持平样本上 `|ΔQ|` 校准；②在非持平样本上的 ΔG MAE/秩相关/符号判断 vs 基线。禁止把整体准确率因为零标签太多而抬高。
- 优先训练 **同一固定 π 的 Value**，不修改 Actor、不发布新策略。比较训练/验证损失与超参数敏感性，判断问题是数据可学习性还是 L4 的优化方法。

**E4-B 策略迁移**
- 若同策略预测有效，把其 ΔQ 应用于下一版冻结策略的独立 CF，测量性能衰减；结合行为变化、κ、Correction判断政策更新导致的分布/标签漂移。
- 若只在同策略有效，优先考虑稳定的 policy evaluation → 小步 policy improvement → 对新 π 重新评价，不需推翻大脑。不要跨不同 π 混合 Q 标签当作同一真值。

**E4-C 只有在 E4-A 确认有可学信息时再决定架构改造**
- 若简单基线优于现有 Value，优先改 L4 监督方法：分层采样零/非零 CF、增加每批不同经济差异、明确 ΔQ 的 paired loss 与刻度；有证据后再考虑专用 Advantage head。
- 若简单模型与 Value 都无法样本外预测，先研究新因果输入的增量信息（更长周期、OI、盘口/跨品种等，按独立留出验证），不要靠加网络深度或再做 10x。
- 若 Q 预测准确但 Actor 决策仍错误，才考虑将“经济优先 / Quality 次优先”落实为受控的融合层，并分析老师与 Q 冲突时的经济差异。

## 7. 验收与边界

- 不以盈利、80% CF、固定胜率或新 Gate 阻断探索。E4 的判断标准是**可分辨机制**，而非一开始要求交易赚钱。
- DEV FG409、既有 PAPER 已多次查看，适合机制诊断，不用它们反复调参后宣称独立泛化。保留封存 TEST；为最终比较预先指定新的未使用数据。
- 保持 TP5/SL30、Native 账本、已有 Reward/质量记录、当前已运行的训练产物不变；E4 使用现有训练数据和少量独立 Value/探针实验，不重训 L1–L3、不重新跑完整 1x。
- 下一阶段一个关键结论：**经济价值可预测吗？如果可以，是 Value 没学会、学会后跨策略失效，还是 Actor 没用好？** 先把三种失败原因拆开，再讨论如何提升执行质量。

## 最终决策

**保留 R2 作为经济价值的研究基准，保留 Outcome/分级老师所表示的执行质量，保留完整学生闭环。下一项研究选择 E4 同策略价值可学习性与策略迁移检验，而非直接改模型。**
