## 设计

**参考轨迹**：π_k 自己的正式 TRAIN 采集（`run.collect`）。
- 每个市场 cursor 一个决策，从第一分钟一直到 MAIN_ROLL 真终止，所以每个 cursor 的回报都完整。
- 折扣：γ = 332/333，按有效市场分钟计（A4，与严格老师同口径）。
- 决策 t 那一步的奖励记为 r_t，反馈在 t+1：G(t) = r_t + γ^{advance(t,t+1)} · G(t+1)。

**分支（同初态 ADD / WAIT）**：起点是参考轨迹上每个“空仓且 ADD 合法”的决策。
- π_k 执行的那个动作，回报就是 G_ref(t)。
- 另一个动作在分支里执行。恢复同一 Native 账户、同一市场记忆和同一 policy 种子计数，强制执行首个动作。
- 之后由同一个冻结 π_k 做正式 argmax。强制那一步也照常调用策略，所以记忆和种子与参考同步推进。

**汇合**：汇合点 c 需同时满足：
- 分支与参考在同一 cursor 都空仓；
- `position_state`、`action_mask`、`account_native` 逐位相等；
- min(参考从 c 起的最低权益) + min(权益差, 0) ≥ 资金下限。

**资金下限**：已持保证金，加上 4 次 3 手 ADD 的成本（按合约最高价和最贵条款）。权益在下限以上时，资金既挡不住 ADD，也改变不了 cover 类账户输入。

**为什么汇合后完全一致**：
- 市场脑外生，两边看到同一市场记忆和同一账户输入，所以 π_k 做同样的决策；
- Native 的交易和奖励只取决于市场和持仓，与现金无关。

**汇合后的回报**：G_branch(t) = Σ_{t≤i<c} γ^{advance(t,i)} · r_i + γ^{advance(t,c)} · G_ref(c)，结果精确，不需要尾值。

**见证**：汇合时，在同一进程里用同一个编译后的策略，把分支在 c 处的 (z, 动作) 与本进程重放主轨迹时 c 处的结果比较。不相等就报错。

**状态**：
- 汇合或到达真终止 → `VALID_COMPLETE`；
- 数据截断或超过步数上限 → `NOT_COMPARABLE`，不给数值标签；
- 本版不产生 `VALID_ESTIMATED`。

**Q 目标**（只属于 π_k，A6 2.4）：
- `q_real`：每行已执行动作的完整回报，来源 `STUDENT_EXECUTED_NATIVE`；
- `q_cf`：fork 点另一动作的分支回报，来源 `VERIFIED_CF_NATIVE`。

**L4**：
- `opt_l4` 只更新 value 组；上游全部 SG，带 burn-in。
- 三项损失：
  - `L_q_real`：已执行动作的 Q 回归 G；
  - `L_q_cf`：另一动作的 Q 回归分支 G；
  - `L_q_pair`：ΔQ = Q_ADD − Q_WAIT 回归 ΔG = G_ADD − G_WAIT。
- 回报完整，所以不用 target copy；没有 Actor 损失。

**π_{k+1}**：新快照写入 β_Q 和 κ_Q（`auto` = 训练段有效对 ΔG 的标准差）。Q 只通过 anchor = β_Q · clip(ΔQ/κ_Q, ±3) 进入 z。

**Q → Reasoning 的投影**（`reason_q`、`gate_q`）：仍为零，因为 S3 不训练 decision 组，它们要到 S4 才开始学。

- L4 管线可用：只改 value 组和 `opt_l4`；`train-value` → `freeze` 能记录 β_Q/κ_Q；pi1 的 z 与 pi0r 的差恰好等于 anchor。
- 但是，FG809 单合约的 Q^{pi0r} 教材训练出的 ΔQ 在两个留出集上都不如常数答案。pi1 是可运行的候选，其 anchor 的价值还没有证据支持。
- 后续可选方向（本轮未做）：
  - 生成更多合约的 CF 教材；
  - 按留出集早停或选 checkpoint；
  - 在提高 β_Q 之前，要求留出集上的 ΔQ 优于 `constant/sign_agree` 和常数 MSE。
