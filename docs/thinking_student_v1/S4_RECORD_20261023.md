## 设计
**L3 = 先验刷新**：`loss = s_demo · L_policy_demo + s_reason · L_reason`，两个系数都是 1。两项用同一批严格 L2 示范行（有效且非平局）、同样的类别权重和 burn-in。

**`L_policy_demo` 的教学视图**：logits 取 `[0, correction]`，不含 anchor。
- 无论 β_Q 取何值，先验收到的梯度都相同，所以残差不会学去抵消 Q（A6 2.3）。
- β_Q = 0 时与 S2 的 L3 完全相同，pi0 系列的语义不变。
- 正式 z 仍是 anchor + correction。评估同时报告先验视图的 ADD 率（`policy/add_rate`）和带锚点正式 z 的 ADD 率（`policy/formal_add_rate`）。

**`L_reason`**：
- `reason_pref` 回答“严格 TRAIN Oracle 认为 ADD 严格优于 WAIT”，损失是 BCE。
- 目标来自独立的严格 L2 示范（`STRICT_L2_DEMO`），不使用 ΔQ、ΔG_CF，也不使用 Oracle 的数值价值。
- 按前向结构，`reason_pref` 的梯度只到达 Reasoning 通路：`reason_in`、`reason_q`、`reason_norm`、`reason`、`reason_pref`。
- `reason_pref` 不进入 z，不是第二个 Actor。

**Q → Reasoning**：
- `reason_q` 与 `gate_q` 读停止梯度后的 Q 上下文，零初始化。
- S2/S3 训练 L3 时 Q 恒为 0，这两个投影从未得到梯度。
- Q 经 L4 监督后不再为 0，两项示范 Loss 开始训练它们。
- 没有任何以 sign(ΔQ) 或 ΔG 为目标的监督。

**一轮改进**在同一个 run 目录完成：
1. `train-value`：从 π_k 出发，用它自己的 CF；
2. `train-policy`：先验刷新；
3. `freeze` π_{k+1}：`freeze` 从该 run 全部 checkpoint 中收集每类报告的最新一份，`policy.json` 的 `teaching` 同时记录 `train_value`、`train_policy` 和 `value_anchor`。

**不做**：
- `L_policy_pref`、`L_align`、`L_policy_rl`；
- 按效果调 β_Q；
- 早停；
- 多合约。

## 小结
**一轮策略改进在真实数据上完整跑通**：
1. 冻结的 pi1 生成精确 CF 教材：1357/1357 完整；
2. L4 学 Q^{pi1}；
3. 同一 run 内做 L3 先验刷新（示范 + `L_reason`）；
4. 冻结 pi2（β_Q 1，κ_Q 0.2664）；
5. pi2 正式采集并 `check`：违规 0，facts 57/57 一致；
6. CF(pi2)：1614/1614 完整，作为下一轮的 Q 教材；
7. 用当前 Q 在 Q^{pi2} 上只做评估。

**结构上的预期都成立**：
- 先验刷新不看锚点（单元测试 2）；`L_reason` 只训练 Reasoning 通路（单元测试 1）；
- z_pi2 − z_pi1 = Δanchor + Δcorrection，偏差 4.8e-7；
- Q 上下文只靠独立示范开始学习：
  - `reason_q` 范数从 0 变为 0.437；
  - 把 Q 置零后，先验平均变化 0.68，翻转 72 / 1357 行；
- `policy.json` 完整记录了这一轮的教学来源（`train_value`、`train_policy`、`value_anchor`、`reasoning`）。

**学习效果没有留出证据**：
- ΔQ：干净的 8192 行诊断再次不优于常数的符号答案（0.761 对 0.777），而且 3000 次更新后过拟合。
- L3：示范 NLL 和 `L_reason` 在留出集上都差于常数 0.84，并且随刷新变差。
- pi2 与 pi1 的 TRAIN 成绩差别很小：奖励 −11.97 对 −11.93，净盈亏 −12066 对 −12852。
- 所以 pi2 是可运行的下一版候选，但不能说它更好。

**可能的原因**（未单独验证）：
- 与 S3 相同：只有一个合约、约 4 个月，样本对高度相关，ΔG 由几百分钟后的行情决定；
- 严格示范只有 276 个 ADD，留出段只有 28 个；
- 2048 行留出每次都只落在 08-03 一天。

**后续可选方向**（本轮未做）：
- 多合约教材与采样：`brain.md` 2026-10-23 新增的正式训练流程建议 18 合约 L1–L3 先行，并做轻量多合约 Sampler；
- 按留出集早停或选 checkpoint；
- 在提高 β_Q 之前，要求 ΔQ 优于常数答案；
- 在 DEV 上做 Teacher-free 评估（S5）；
- 下一轮 L4 直接用 `cf/pi2`，`$NEXT` 已从 pi2 建好 run。
