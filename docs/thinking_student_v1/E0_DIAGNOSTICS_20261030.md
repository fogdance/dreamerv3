## 结论：下一轮优先改 Reward（对齐经济目标）；Outcome / Q / Actor 暂不动

**原因：**
1. **现有实验没有找到稳定、可泛化的入场前 SL30 信号。** 这不证明信息不存在（e1.md Review 修正，2026-10-30）：探针只有 20 个手工特征，学生是另一种表征，两者在合约留出上都失败。两条证据：
   - 学生自己的 Outcome：样本内 AUC 0.64–0.99，样本外 DEV / PAPER 为 0.39–0.54。
   - 与学生无关的梯度提升探针：样本内 0.82，按合约留出平均 0.50（0.46–0.55），DEV 0.52，PAPER 合并 0.52。

   两者在样本外都接近 0.5，所以问题不在 Outcome 网络的结构或训练方式。换更好的模型去拟合同样的输入，很可能还是只会记住训练集。
2. **在没找到信号的情况下，现在的 Reward 仍然奖励进场。**
   - 盈亏平衡胜率：Reward 约 80%，Q 用的折扣回报约 74%，净盈亏需要 86.6%。
   - 市场本身的随机进场胜率约 80–86%（TRAIN 80.9%，DEV 85.9%，PAPER 80.0%）。
   - 所以在 Reward 意义上，"随便进场"大致不亏甚至略赚，在钱的意义上却在亏。
   - 学生实际 82% 的胜率在 Reward 上是正的（所有运行 +36～+80），净盈亏是负的。

   **学生忠实地优化了一个与赚钱不一致的目标。**
3. **因此先研究 Reward。** 目标对齐后，在没有信号的市场里，正确的价值是"不进场"。但这是待 E2 验证的假设，不保证学生会这样学（e1.md）：最可能的结果是接近全部 WAIT、亏损趋近 0，这是规避负期望，不等于学会择时。另外，若保留折扣 γ，较晚的 SL 仍会被少罚，所以 E2 要把奖励（R1）与折扣（R2）分开比较。

| 模块 | E0 证据 | 判断 |
|---|---|---|
| **Reward** | 单笔与净盈亏同号 99%。但盈亏平衡胜率不同：Reward 约 80%，Q 折扣回报约 73–75%，净盈亏 86.6%。所有运行 Reward 为正，净盈亏为负 | **第一优先。** 冲突是尺度问题，不是方向问题：SL 的 Reward 只有 TP 的 4.2 倍，折扣后 2.8 倍，真实亏损是 6.45 倍 |
| **Outcome** | 样本外 p_sl_h 的 AUC：DEV 0.39 / 0.54，PAPER 0.51 / 0.53，校准平坦；10x 在 TRAIN 上 0.99（记忆化）。独立探针按合约留出也只有 0.50 | **暂不改网络。** 瓶颈是输入里缺少可泛化的信息，不是 Outcome 的结构。以后若要提高胜率，需要研究新的信息来源（输入），这是单独的研究问题 |
| **Q** | 标签 ΔG 与 ΔPnL 同号 91–99.8%，定义没问题。1x 秩相关约 0，锚点翻转 41% 与 ΔG 同向（是否有害要看幅度和累计影响，由 E1 直接检验）。10x 的秩相关只来自样本内记住的 ADD 分叉 | **暂不改定义。** Reward 对齐后 ΔG 会随之改变。β_Q = 1 的有害翻转可在 E1 用冻结权重确认 |
| **Actor** | 实际进场的止损率（PAPER 18.0% / 17.9%）略低于候选基准（22.1% / 20.2%） | **暂不改。** 没有可利用的信号让决策融合去用 |

在 Review §7 核心问题上：**只用入场前的状态，学生的表征与 Outcome/Q 在样本外不能识别会触发 SL30 的 ADD，一个与学生无关的简单模型同样不能。** 所以目前看不到"决策融合或价值目标没用上信号"的证据；但"市场输入里没有信号"只是现有方法下的结论，不是证明。在找到信号之前，目标是否与赚钱一致，就决定了学生的行为。

- **Reward 赏罚比例与真实盈亏不一致：** SL 的 Reward 只有 TP 的约 4.2 倍（−3.09 / 0.73），真实亏损却是盈利的 6.45 倍（−1,823 / 282）。
- **折扣让 Q 看到的止损更轻：** 止损通常来得晚，按 γ = 332/333（每市场分钟）折扣后只剩 −1.6 左右，是 TP 的约 2.8 倍。所以 Q 的盈亏平衡胜率只有约 74%。
- **因此学生在 Reward 意义上"做对了"：** 胜率 82% 高于 Reward 门槛约 80%，Reward 合计为正，但净盈亏为负。这是**尺度冲突**：单笔同号 99%，冲突全部发生在 80%–86.6% 这一段胜率上。
- **adverse10 惩罚：** 约 28–36% 的止盈单要先付 −0.5，所以止盈 Reward 平均只有 0.73–0.86，低于 1。

## E0.2 入场前信息能否预测 SL30

**设定：**
- **候选：** 学生自己轨迹上每个合法空仓分钟。（`unfinished_lots` 是动作之后记录的，所以"决策前空仓"用前一步的值判断。DEV 的 221 / 260 笔实际交易与当时事实逐笔一致，事实中的进场都是决策光标 +1。）
- **标签：** 该光标的 Native 事实。只用 TP5 和 SL30，其他退出单独计数。
- **TRAIN 是样本内：** L1–L3 用全部 18 个 TRAIN 合约训练过，没有真正留出的 TRAIN 时间块。
- **样本外：** DEV FG409（本次用语料函数生成事实，32 个光标的 Native 逐分钟核对通过，不进语料目录），以及 PAPER 5 个合约（已曝光，只作解释）。

- **PAPER 各合约结果不稳定：** p_sl_h 的 AUC 在 0.38–0.75 之间来回，方向也会反转，所以合并后接近 0.5。
- **校准：**
  - 10x 在 TRAIN 上几乎完美：预测 0.98 对应实际 1.00，预测 0.00 对应实际 0.00。
  - 10x 在 PAPER 上，预测 0.00 到 0.95，实际 SL 率都在 0.17–0.25 之间。
  - 1x 在 DEV 上，预测越高，实际 SL 反而越低。
- **静态剔除最危险的候选**（按 p_sl_h，不考虑替代交易）：
  - DEV 1x：TP 率从 0.902 降到 0.869。
  - PAPER 1x：0.779 → 0.782 / 0.781 / 0.777 / 0.789，基本不变。
  - PAPER 10x：0.798 → 0.797 … 0.820。剔除一半候选，TP 率也只升 2 个百分点。
  - 都远达不到盈亏平衡所需的 86.6%。
- **按 MAE 分三类**（TP 且 MAE<5、TP 且 MAE≥5、SL）：在 DEV 上，三类的 p_sl_h、p_tp_h、ΔQ 中位数几乎相同（1x：0.189 / 0.196 / 0.170），所以学生事先区分不出"会先逆行再止盈"和"会止损"。
- **实际进场的止损率低于候选基准：** PAPER 上 18.0% 对 22.1%（1x），17.9% 对 20.2%（10x）。Actor 有少许选择能力，但 AUC 仍接近 0.5，所以它不是一个可以拿来设门槛的单调风险分数。

**独立探针**（`probe.py`，与 TS 模型无关）：
- **模型与特征：** HistGradientBoosting，用 20 个入场前特征，按交易方向取符号。特征包括 1/5/15/60/240 分钟收益，15/60/240 分钟区间、区间内位置、波动、成交量比，以及时刻和星期。
- **训练与检验：** 在 18 个 TRAIN 合约的全部事实上训练，共 476,607 行，SL 率 18.4%；按合约做 6 折留出。

| 检验 | AUC |
|---|---|
| 样本内（训练集自身） | 0.82 |
| 按合约留出（18 个合约） | 平均 0.504，最低 0.459，最高 0.549；合并 0.497 |
| DEV FG409 | 0.522 |
| PAPER FG501 / 505 / 509 / 601 / 605 | 0.556 / 0.500 / 0.563 / 0.428 / 0.646（FG605 只有 3,391 个候选，未走完） |
| PAPER 合并 | 0.524 |

- **单个特征：** 最强的是近 15–240 分钟的波动或区间，在 DEV 和 PAPER 上 AUC 约 0.53–0.58，但方向随合约改变（如 FG509 的 vol_240 为 0.397，FG601 为 0.578）。
- **结论：** SL30 在这些输入下只是不同行情阶段的基准率差异（各合约 SL 率：TRAIN 8.6–26.3%，DEV 13.6%，PAPER 15.2–30.5%），没有稳定的入场前排序信号。

## E0.3 Q 的独立预测能力

**设定：**
- **配对：** π_k 在每个分叉的 ΔQ，配 π_k 自己 CF 的 ΔG（VALID_COMPLETE）。第 k 轮用 π_k 的 CF 训练出 π_{k+1}，所以这批 CF 从未用来训练 π_k 的 Q。
- **对照：** 多数符号基线，即总是猜 ΔG 的多数符号。
- **ΔG 与 ΔPnL：** 在 COUPLED 配对上，用分支交易减去参考轨迹在同一区间的交易，算出 ΔPnL。

| 运行 | π₁–π₈ 秩相关 | 符号一致 vs 多数基线 | EXACT_STATE 秩相关 | 学生 ADD 处分叉（first=0） | 学生 WAIT 处分叉（first=1） | 锚点翻转：次数 / 与 ΔG 一致 | ΔG 与 ΔPnL 同号 |
|---|---|---|---|---|---|---|---|
| 1x | −0.04…0.05（均值 0.006） | 0.481 vs 0.568 | 0.015 | 0.019 | −0.051 | 828 / **41.2%** | 91.2–99.2% |
| 10x | 0.34…0.58（均值 0.458） | 0.727 vs 0.771 | 0.066 | −0.036 | 0.527 | 339 / **45.1%** | 97.7–99.8% |

- **Q 的标签没问题：** 在耦合分叉上，ΔG 与 ΔPnL 同号 91–99.8%，所以 ΔG 的方向与经济结果一致。问题出在 Q 的预测能力，不在 Q 的定义。
- **1x 的 Q 没有预测能力：** 秩相关约 0，符号一致率低于多数基线。锚点翻转的 828 个决策中，ΔG 支持翻转的只有 41%，所以 β_Q = 1 时，这些翻转平均在添乱。
- **10x 的秩相关只来自一类分叉：** 学生原本 WAIT、分支去 ADD 的 FUNDS_SAFE 分叉，也就是"如果在这里新开一笔，会不会止损"。这正是 10x Outcome 在 TRAIN 上记住的信息（第 1–6 轮的 CF 合约虽然 L4 没见过，但 L1–L3 都训练过）。在 EXACT_STATE 配对和学生自己 ADD 的分叉上，秩相关约 0。在 DEV 上，ΔQ 对 SL 的 AUC 只有 0.43 / 0.54。

## E0.4 评估口径核查

**PAPER，学生账户：**

| 运行 | 平仓 | SL | TP/SL 同 bar 歧义 | 入场 bar 即 SL | 1 bar 内 SL | SL 滑点（笔数 / 点） |
|---|---|---|---|---|---|---|
| 1x SL30 | 721 | 129 | 0 | 0 | 0 | 5 / 32 |
| 1x SL16 | 1,133 | 363 | 0 | 2 | 8 | 11 / 53 |
| 1x SL5 | 3,361 | 2,442 | 5 | **638** | **1,028** | 17 / 101 |
| 10x π₄ SL5 | 5,101 | 3,679 | 7 | **807** | **1,286** | 17 / 92 |

**两个缺口都对上了：**
- **SL5：** Review 中 SL5 那 −6,060 元差额，等于 101 点滑点 × 60 元 = 6,060 元。
- **SL30：** 1x 的 −3,354 元差额（−68,424 对 −71,778），等于滑点 32 点 × 60 = 1,920 元，加 3 笔主力换月退出 −1,434 元。

**SL5 是怎么输的：** TP/SL 同 bar 歧义只有 5–7 次，不是主因。主因是 26% 的 SL 在入场那一分钟就触发，42% 在 1 根 bar 内触发。

**随机对照：**
- 随机账户的实际成交（1x 679 笔 / 10x 839 笔）与学生（722 / 855）差 2–6%。
- 持仓占用率也接近（0.739 对 0.716；0.894 对 0.892）。
- 所以对照基本公平。
- PAPER 每个合约都重置初始资金，所以合计亏损不是单个 30 万账户连续亏出来的（见 `paper.py` 说明）。

**FG501 单独看：**

| 运行 | 全部：学生 / 随机 | FG501：学生 / 随机 | 去掉 FG501：学生 / 随机 |
|---|---|---|---|
| 1x π₆ | −72,420 / −83,170 | −38,061 / −47,365 | **−34,359 / −35,805（只少亏 1,446）** |
| 10x π₄ | −84,774 / −106,435 | −50,952 / −54,808 | **−33,822 / −51,627（少亏 17,805）** |

- **1x 对随机的优势几乎全部来自 FG501。**
- **10x π₄ 在 FG501 之外仍明显好于随机。** 但如 E0.2 所示，这种选择能力不是可单调利用的风险排序。

**成交价的点差规则（用户 2026-10-30 发现，决定只记录、不改规则）：**
- **例子：** 1x π₆ PAPER FG501 第 775 步，bar 2024-08-21 22:26（开 1319 高 1319 低 1318 收 1318）开空，成交价 1317，比该 bar 及前后几根的最低价低 1 跳。
- **机制：** `entry_env.py::_price` 把所有报价都算成原始价 ±（spread + slippage），并朝不利方向取整到 tick。合约条款是 `spread: 1.0`、`slippage: 0.0`，所以开空按收盘价 − 1 成交。
- **范围：** 这是 f65f7c2 起就配置好的成本模型，TRAIN / DEV / PAPER 完全一致，不是代码回归。
- **出场也走同一点差：**
  - 空单 TP 价 1312（成交价 − 5），要求 bar 最低价 + 1 再穿过 1 跳，即最低价 ≤ 1310；
  - SL 价 1347，要求最高价 + 1 ≥ 1347，即最高价 ≥ 1346；
  - 从决策 bar 收盘价算，实际行情几何是 **TP 8 点 / SL 28 点**，不是 TP5/SL30；
  - 盯市同样含点差：入场后权益立即下降 249 = (1321 − 1317) × 60 + 9。
- **影响：**
  - 1x PAPER 722 笔入场中有 140 笔（19%）成交在决策 bar 最低价之下，都是收盘价等于最低价的空单。
  - 每笔入场比按收盘价成交多付 1 点（60 元），全段约 43,320 元。
  - 单笔盈亏（TP +282 / SL −1,818）和 86.6% 的盈亏平衡胜率都从成交价起算，已经包含这项成本。点差的作用是降低 TP 的命中概率，不改变单笔盈亏。

## 对下一轮的建议（E1/E2 之前确认）

1. **E2 第一支，只改目标：** 在独立研究分支，把学习目标对齐到含费用和真实 SL 的净盈亏。
   - **保持不变：** TP5/SL30、模型结构、数据划分、训练参数。
   - **检验标准**（只在 TRAIN/DEV 上）：
     - Reward 的盈亏平衡胜率等于净盈亏的盈亏平衡胜率；
     - DEV 上的进场次数和净亏损下降；
     - 学生不能比 WAIT 更差。
   - 预期不是赚钱，最可能是接近全部 WAIT、亏损向 0 收敛（e1.md：这是规避负期望，不是择时）。即使学生全部 WAIT，事实表（每个时点）和 CF 强制分叉仍提供 ADD 的后果，学习数据不会断。
2. **E1，冻结权重，成本低：** 用 β_Q = 0 重考 1x π₆ 和 10x π₄ 的 DEV，确认 1x 的锚点翻转是否有害（E0.3 显示只有 41% 有利）。
3. **Outcome、Q、Actor 本轮不改。** 想提高胜率，需要单独研究新的信息来源，比如更长周期、跨品种、盘口或基本面，而不是换网络结构。新输入的价值要先用 `probe.py` 这种按合约留出的探针证明，再进学生。
4. **停止增加 10x 预算，也不再扫描止损：** E0.2 显示更多训练只会让训练集记得更牢；E0.4 显示 SL5/SL16 主要改变了交易频率和入场 bar 即止损的比例。
