# E1 / E2 实验Review：有实质性进展

两份报告读完后，我认为我们终于找到了一条值得继续探索的路径。不过，需要修正之前对Q的判断。

E1证明：当前Q虽然预测能力弱，但关闭它反而可能让学生交易得更差。

E2证明：把Q的学习目标改为接近真实经济收益的无折扣回报后，在一次受控训练中，学生的DEV亏损明显减少。

这两个结果结合起来，比单独讨论Q的Spearman相关性更有意义。

关闭显式Q Anchor以后，1x π₆的亏损增加了13,194元。

10x π₄的结果不同：关闭Q只使亏损从−19,380元改善至−17,844元，差异较小。

这说明两个问题：

- 不能因为ΔQ与ΔG相关性接近零，就认定Q的实际决策贡献一定为负。
- Q可能正在发挥一种重要作用：抑制不值得的ADD。

但这里还不能证明Q已经具备真正的价值排序能力。一个整体偏向WAIT的锚点，也可能在负期望市场中减少亏损。

因此，我现在支持保留β_Q=1作为原实验设置，不再主张直接关闭Q，也暂不新增Q质量Gate。

## 三、我认为E2还有三个关键问题需要确认

### 1. 这次不是整个Reward系统都切换了

报告明确写明，R0/R1/R2三次重跑只有CF目标及其生成的S5反馈不同。

也就是说，E2直接验证的是：

经济价值标签 → L4/Q与教学反馈 → 学生决策

而不是把Native Reward、Outcome监督、分级老师以及所有学习阶段都统一更换为新的经济Reward。

这反而是优点：它以很小的修改范围取得了明显结果。但我们不能据此宣称所有大脑模块的目标已经完全对齐。

而且，R2相对R1不仅改变了折扣，还引入了2760分钟的截断。现有结果强烈支持时间折扣和回报范围的定义很重要，但不能严格断言改善全部来自取消折扣。

### 2. R2的改善究竟来自Q，还是S5反馈？

这是我现在最关心的机制问题。

R2相比R0，不仅改变了Q标签，还重新生成了教学反馈，随后执行了L2复习和L5学习。

同时，Anchor翻转出现很大的变化：

|    | ADD → WAIT | WAIT → ADD |
| -- | ---------- | ---------- |
| R0 | 235        | 56         |
| R1 | 636        | 55         |
| R2 | 2,975      | 19         |

这些是在对应轨迹上观察到的决策翻转，不是实际新增或减少的交易笔数。

R2的价值锚点明显更倾向于阻止ADD。它可能更准确地识别了不合算的交易，也可能主要学到了整体偏向WAIT。

只需要增加两次低成本考试，就能先区分一部分原因：

| 冻结Checkpoint | β_Q=1 | β_Q=0 |
| ------------ | ----- | ----- |
| R0 π₇        | 已完成   | 新增考试  |
| R2 π₇        | 已完成   | 新增考试  |

如果R2在β=0时仍明显优于R0，说明收益不只来自显式Q Anchor，更新后的S5/Decision路径也可能有贡献。

如果R2关闭Anchor后优势大幅消失，则说明经济Q锚点是主要贡献者。

这比直接再训练一套新模型更有价值。

### 3. R2可能改变大量精确反事实标签的意义

这是一个需要提前注意的数学问题。

此前FG201成功补出的664条`EXACT_STATE`反事实，耦合时两个账户的资金相同。

假如两条分支从相同初始资金开始，后来在某时刻精确重合、都已空仓，而且整个过程的交易收益都被包含在R2的评价窗口内，那么：

\\[ \Delta G\_{\mathrm{R2}}=0 \\]

原因很简单：两条路径虽然执行了不同交易，但最终回到相同资金和相同未来状态。无折扣的净盈亏总和自然相同。

这在经济上是正确结果，不是计算Bug。

但它也意味着，原来Quality Reward能够区分快慢、逆向波动和交易质量的某些CF，在R2中可能变成价值相等的样本。

因此，R2继续训练之前，建议检查CF的`EXACT_STATE`、`FUNDS_SAFE`、`TERMINAL`三类标签中，实际有多少\\(\Delta G\\)接近零，以及这些标签对\\(\kappa_Q\\)和L4监督的影响。

还有一个边界：R2只计算2760个市场分钟内的收益。若存在窗口结束时尚未平仓的交易，就必须检查其处理方式，不能因为未来亏损没有进入窗口而错误奖励ADD。

## 四、下一阶段我建议这样推进

考虑到这是探索性项目，我不建议因为上述问题而停止R2的连续训练。我们已经有足够理由让这条研究分支继续前进。

E3-A：先完成两次冻结考试

补齐R0 π₇、R2 π₇在`β_Q=0`下的DEV结果。同时检查R2的CF标签接近零比例及2760分钟边界。

不重新训练，不修改任何网络。

E3-B：R2继续运行第8、9轮

从R2 π₇出发，实际完成新学生采集、以当前冻结策略生成新的CF经济价值标签、更新S5、完成L4/L5、发布π₈，再继续π₉。

这一步是核心，因为我们要检验R2能否在连续学习中保持效果，而不只是修复某一轮的退化。不能继续使用π₆的CF来监督新的π₇价值函数。

E3-C：比较连续学习行为

对照R0和R2的π₇、π₈、π₉，关注真实净PnL、ADD数量、TP/SL、回撤、Q的独立CF预测能力，以及Anchor如何改变决策。

不要求每一轮盈利，也不因为某一轮退化就中断整个探索循环。最终泛化结论留给尚未用于研究选型的独立数据。

我建议先采用已有1x预算，不继续做10x，更不需要重新训练L1–L3。新增实现应保持在独立研究分支，复用现有配置与训练入口，不引入新的质量门槛。

## 五、最终判断

截至E2，我对Thinking Student的判断已经发生变化：

原先我们怀疑：Q学不好，所以学生无法形成价值判断。

现在更值得研究的解释是：Q原先接受的长期折扣Quality回报，可能没有充分表达一次SL30的真实经济代价；调整目标后，学生开始更积极地避免负价值ADD。

不过，目前R2仍然亏损，胜率83.3%仍低于约86.6%的盈亏平衡要求，不能说学生已经形成可靠盈利能力。

我明确支持继续R2实验分支。 先完成两次β_Q消融，再让R2真正连续学习到π₉。若效果能够跨轮次保持，我们才有更强的理由将经济Q目标作为下一代Thinking Student的正式研究方向。

比起再讨论增加训练量，现在最重要的是检验：学生能否把这次初步形成的经济风险意识，稳定地继承到下一代学生。
