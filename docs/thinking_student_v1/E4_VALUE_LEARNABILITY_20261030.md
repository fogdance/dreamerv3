# E4：同策略价值可学习性与策略迁移

日期：2026-10-30
依据：`TS_V1_R2_Full_Architecture_Review_20261030.md` 第六节。
判定规则在结果之前写下：`E4_VALUE_LEARNABILITY_20261030/PREREGISTRATION.md`。

**要回答的问题：** 经济价值 ΔG 是否可预测？如果不能，是信息本来就没有，还是 Value 没学会，还是跨策略失效？

**做法：**
- **对象：**
  - π_A = 1x-R2 的 π₈，π_B = 1x-R2 的 π₉，都是冻结策略，本实验不训练、不发布新策略。
  - 每个策略在全部 18 个 TRAIN 合约上采集并计算 CF，命令与 1x-R2 第 9 轮相同，只换路径。
  - 标签用该运行自己的 `q_return.py` 重新标注为 R2，精确性核对全部通过（33 个新 CF）。
- **切分：**
  - 主切分：按合约 6 折（GroupKFold，每折 3 个合约）。
  - 次切分：每个合约按时间，前 70% 训练、后 30% 测试；L4 用 `train-value --holdout 8192`。
- **模型：** 每个模型都只用决策时可见的输入，并且只在训练折上拟合。

| # | 模型 | 输入 |
|---|---|---|
| 1 | 常数：训练折 ΔG 均值 | – |
| 2–3 | Ridge / HistGBR | E0 的 18 个因果价格特征 |
| 4 | Ridge / HistGBR | π_A 在该行记录的回答：Outcome、Q、z、Correction 等 |
| 5 | HistGBR | 2 和 4 的特征合并 |
| 6 | π_A 记录的 ΔQ | 用 π₇ 的 CF 训练，是跨策略基线 |
| 7 | L4 从 π_A 出发，只用训练折合约的 π_A 自己的 CF 重训 | 正式 L4 参数，不含 S5 反馈；500 和 3000 次更新；冻结后在留出合约上连续重放 |

- **对照：** 用 π_A、π_B 自身重放各自的采集，ΔQ 和全部回答都与记录逐字节一致。所以模型 7 和 π_A 之间只有 Value 不同。
- **打分：** 不持平配对和持平配对分开打分。
- **范围：** DEV、PAPER、TEST 都未使用，结论是方向性的。

## 一、标签普查（π_A 自己的 R2 CF）

| 项目 | π_A（π₈） | π_B（π₉） |
|---|---|---|
| fork / 有效配对 | 7,108 / 4,793（覆盖 67%） | 7,609 / 5,101（67%） |
| EXACT_STATE 配对（全部 ΔG = 0） | 2,740 | 2,902 |
| 持平占比 | 57.2% | 56.9% |
| 不持平配对 | 2,050 | 2,196 |
| 不持平中 ADD 更好 | 62.7% | 59.6% |

不持平 ΔG 几乎都是离散的单笔交易差：

| ΔG（元） | 占不持平 | 含义 |
|---|---|---|
| +282 | 58.7% | ADD 分支多一笔止盈 |
| −282 | 21.9% | WAIT 分支多一笔止盈 |
| −1,818 | 6.5% | ADD 分支多一笔止损 |
| 其余 | 12.9% | 多笔组合 |

- 小赢很常见，大亏很少，所以 ADD 更好的占多数，但 ΔG 均值偏负。
- 同频交易下，决定经济差异的主要是"会不会多出一笔止盈"和"少数止损"。

**补充（不在预注册规则里）：** 只看不持平配对，"永远判 ADD 更好"这条规则的符号一致率就是 62.7%，高于所有模型。

**过拟合：**
- 训练折上，GBR 的 ρ 是 0.73–0.76，留出后只剩约 0.1。
- L4 3000 次更新时，训练批次的符号一致率有 0.85–0.95，留出后约 0.51。
- 两者都主要是在记训练数据。

**时间切分（次要）：**
- 各模型 ρ 在 −0.10 到 +0.06 之间。
- L4 时间尾部运行在留出部分的 q_pair 误差：500 次 0.058，3000 次 0.061，都比常数的 0.050 更差。训练前是 0.056。

**判定：E4-A = `NO_SIGNAL`。**
- 没有任何模型满足"汇总 ρ ≥ 0.05，并且至少 13/17 个合约 ρ > 0"。
- 最接近的是 L4 3000 次（+0.052，12/17）和 GBR 价格 + 回答（+0.108，10/17）。

## 三、E4-B：跨策略（按预注册不解读，只记录）

| 模型 | ρ(π_A) | ρ(π_B) | 比值 |
|---|---|---|---|
| GBR 价格 + 回答 | +0.108 | +0.052 | 0.48 |
| L4 500 次 | +0.050 | +0.038 | 0.77 |
| L4 3000 次 | +0.052 | +0.033 | 0.64 |
| 各自记录的 ΔQ | −0.085 | −0.036 | – |

- π_A → π_B：κ_Q 0.196 → 0.228。FG201/205/209 的 ADD 率翻倍（例如 FG201 9.0% → 20.2%），平均 Correction 普遍变得更负。
- 本来就很弱的同策略信号，迁移到下一版策略后又减少了 25–50%。三个模型都是 `TRANSFER_DECAYS`。
- 因为 E4-A 不是 `VALUE_LEARNS`，这些数字只作记录。

## 结论

1. **评审提出的三种失败原因，这次能区分出来的是第一种：**
   - 在当前输入下，同一策略的经济 ΔG 在留出合约上几乎不可预测。
   - 输入包括：现有冻结表征加 Value、π_A 的 Outcome/Q 回答、18 个因果价格特征。
2. **"跨策略失效"是存在的，但不是主因：**
   - 同策略重训后，ρ 从跨策略的 −0.085 提高到约 +0.05。
   - 但 +0.05 本身仍然接近零，换到下一版策略后又降到约 +0.035。
3. **"Value 没学会"也不是主因：**
   - L4 和独立的 GBR/Ridge 探针给出相同的结论。
   - 训练集上拟合得很好，留出集上无效：这是可推广的信息不足，不是优化失败。
4. **标签的形态解释了为什么难：**
   - 约 80% 的不持平 ΔG 是 ±282 元，也就是一笔止盈出现在哪个分支。
   - 真正决定经济价值的大亏（−1,818 元）只占 6.5%。
   - 这和 E0 的发现一致：样本外 pSL 的 AUC 约为 0.5。
5. **局限：**
   - 每个策略只有约 2,000 个不持平配对，有 17 个合约可用于判定，有些合约不到 40 个配对。
   - 表征（L1–L3）在这 18 个 TRAIN 合约上训练过，所以合约留出并不是完全独立的数据。
   - 只测了一对策略。

**按评审第六节 E4-C，结果指向第二个分支：** 如果简单模型和 Value 都无法样本外预测，应先研究新的因果输入能提供多少增量信息，而不是改 L4 监督或加网络。本轮不擅自开始。可以讨论的方向：
- 新的因果输入，例如更长周期、持仓量、盘口或跨品种信息，按独立留出验证。
- 标签本身：
  - 是否把"会不会多一笔止盈"的计数差异，和"会不会触发止损"的风险差异分开学习。
  - 是否只用 ADD 的首笔交易结果做经济目标，以减少后续路径带来的噪声。
