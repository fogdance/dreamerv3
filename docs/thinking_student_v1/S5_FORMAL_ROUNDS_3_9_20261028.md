## 7. 发现与限制

- **L2 复习和 L5 每轮都采样同一批窗口。**
  - 采样种子是 `[seed, 阶段, 本 learner 该阶段已有的更新数]`。每轮都新建 learner，这个更新数从 0 开始；语料列表（18 个 TRAIN 合约）也每轮相同。
  - 所以每轮的 L2 复习都用同样的 200×16 个窗口，L5 都用同样的 100×16 个窗口，七轮复习只覆盖了语料的一小块。
  - L4 的数据每轮来自不同合约的 CF，不受影响。
  - 这不阻断运行，按要求没有修改。10x 每轮 L2 复习 2000 次、L5 1000 次，会有同样的重复。
- **训练批次指标不是训练曲线。** `rounds_report.md` 中 L4 和 L2 复习的“first → last”，是第 100 次和最后一次更新时单个 batch 的值。由于窗口序列每轮相同，各轮的 first 值几乎一样。判断复习是否起作用，要看下一轮策略在新采集上的 Outcome 和 DEV。
- **CF 覆盖率低。** 除第 3 轮沿用的两份旧 CF 和第 8 轮 FG109（0.81）外，Astra CF 的覆盖率都在 0.43–0.68，L4 全部按探索处理。有效对偏向在探测步数内就能合并或到达终点的分叉，可能不代表全部决策。
- **只有 DEV 是同一数据上的比较。** 从第 4 轮起，两条线的策略不同，采集也不同；ADD/WAIT、Outcome、Q 指标都是各自策略在各自采集上的值。

## 8. 结论

- S5 持续学习闭环在正式 run 上完整跑了 7 轮。每轮都产生了新的冻结策略、checkpoint 和 Teacher-free DEV 结果，并通过核对。
- **学到的：** 多数轮次中 Outcome 的 TP/SL 区分好于开发 run；DEV 也一直好于开发 run。
- **没学到的：**
  - Q 对 ADD/WAIT 的排序，两条线都没有超过随机。
  - 学生几乎一直在场内，ADD/WAIT 没有表现出选择性，DEV 收益与随机进场相当。
- 从结果看，下一阶段的瓶颈在价值和决策（Q 学习、ADD/WAIT 选择），不在 Outcome 或训练流程。具体研发方向由用户决定。
