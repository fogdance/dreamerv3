# E1：冻结权重，关闭 Q 的显式 Anchor（β_Q = 0）

日期：2026-10-30
依据：`TS_V1_Integrated_Review_20261030.md` §6，以及 `E1_REVIEW_e1_20261030.md`（e1.md）

**做法：**
- 用冻结的 1x π₆ 和 10x π₄ 在 DEV FG409 上各做两次完整的 Native 闭环考试：β_Q = 1（冻结时的设置）和 β_Q = 0。
- β_Q = 0 只关闭显式 Anchor，Q 仍作为上下文进入 Reasoning/Gate。
- 不训练，不改权重和交易规则。随机对照用每次运行学生自己的 ADD 率，5 个种子。

**判定规则**在看结果前写下：`E1_BETA_Q_20261030/PREREGISTRATION.md`。
- d = 净 PnL(β_Q=0) − 净 PnL(β_Q=1)；s = β_Q=1 那次考试中随机账户净 PnL 的标准差。
- d > s：Anchor 有害；d < −s：Anchor 有帮助；否则不确定。
- 前提：β_Q = 1 的重跑必须与原正式 DEV 考试逐项相同。两个策略都相同（ADD、TP/SL、净 PnL、Reward、最大回撤）。

## 解读

**1x：Anchor 主要起"刹车"作用。**

β_Q = 1 路径上有 948 次 Anchor 翻转：
- **927 次 ADD → WAIT：** 关掉 Anchor 后，ADD 从 221 次增加到 284 次。
- **只有 21 次 WAIT → ADD：** 这 21 笔交易是 15 TP / 6 SL，净亏 −6,678。

关掉 Anchor 后，单笔表现也变差了：
- 净 PnL 每笔从 −72 降到 −103，TP 率从 83.3% 降到 81.7%。
- 学生对同频随机账户的优势从 +4,235 变成 −3,831。

所以，被 Anchor 拦下的那些 ADD 平均比留下的更差。Anchor 不只是减少交易次数，也带有一点筛选作用。但这仍是单个合约上的结果。

这也印证了 e1.md 的修正：E0.3 的"41% 翻转方向与 ΔG 一致"不能直接说明 Q 有害。拦下的 ADD 和放行的 ADD，价值幅度不同；累计效果要靠闭环来看。

**10x：Anchor 几乎不起作用。** 只有 61 次翻转（其中 2 次 WAIT → ADD），两种设置的结果相差不到随机标准差的三分之一。

**Q 在冻结 1x 的 Reasoning/Gate 中仍作为上下文参与决策。** E1 只说明了显式 Anchor 的作用，没有完全隔离 Q 的作用。由于结论是"保留"，这次不需要进一步隔离。

## 对下一步的影响

1. **Q 不是有害模块，不降低它的投票权。** 本轮保留 β_Q = 1，E2 不需要先处理 Q。
2. **1x 的 Anchor 有效，是因为现在的交易整体是负期望，少交易就少亏。**
   - 这和 E0 的 Reward 结论一致：经济目标对齐后，Q 的"刹车"会得到正确的价值依据，而不是靠偶然。
   - E2 中 ΔG 必须按新 Reward 重新标注（e1.md 第五节）。
3. **局限：**
   - DEV 只有一个合约，并且已经用来选过 π₆/π₄，所以这是 Q 投票权的诊断，不是泛化结论。
   - 已经曝光的 PAPER 和 FG701 live 都不用于这个判定。
