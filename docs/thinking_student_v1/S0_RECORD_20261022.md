# S0 记录 — 最小完整学生前向 + 训练底座（2026-10-22）

分支：两个仓库均为 `feat/thinking-student-v1-20261022`。基线：dreamerv3 `990f61f`，gym `ff21209`，均来自 `integration/s3-next`。

## 改动

### DreamerV3：`dreamerv3/thinking_student/`
- `market.py`：Market Brain。
  - `MarketEncoder` 只读三类市场输入：1m、15m、partial MACD。
  - `MarketRSSM` 包装原 RSSM 核心，参数名和形状不变；动作槽固定输入零向量，学生动作无法进入市场演化（A2/R01）。
  - RSSM 只在 `is_first` 时重置，即行情不连续时。
- `brain.py`：
  - `AccountEncoder` 读取 position_state、account_native、mask 和有效位。
  - `SharedFusion`。
  - `OutcomeBrain`：竞争风险输出，共 15 类，分箱 5/15/30/60/120/240/480 × {TP, SL} 外加存活类。另有 early10、MAE、Quality 和 evidence 输出；非法 ADD 时有效位为 0。
  - `ValueBrain`：输出层零初始化，因此起始时 Q_ADD == Q_WAIT。
  - `DecisionBrain`：按 A5 公式实现。Reasoning、门控和 ΔQ 锚点的输入都经过 SG（F-01）。最终 logits 为 `[0, z]`，经 Native mask 屏蔽。
- `student.py`：
  - `StudentModel.policy` 是唯一的决策路径；`mode='eval'` 表示同一分布下的贪心执行。
  - 返回 B1.2 答卷（`answer/*`）。
  - S0 训练实现 L1，包括 `L_market`（RSSM KL 加 market_seq 重建）和 `L_account`（账户嵌入保留持仓与 can_add 事实）。
  - 参数组写成 `GROUPS` / `STAGE_GROUPS` 两张表。
- `transfer.py`：从 F1 继承 `enc/*` → `market_enc/*`（minute 首层只保留第 2:1082 行市场输入）、`dyn/*` → `market_dyn/*`，以及市场相关的 `dec`。打印 reused、sliced、initialized 三份清单。
- `run.py`：
  - `rollout`：学生自主 Native 交易，答卷写入 jsonl。
  - `train-market`：用 P0–P4 corpus 窗口跑 L1。
  - Checkpoint：`ckpt/<step>/agent.pkl` 加 `latest`；启动时自动 resume，不做 Hash 检查。
- `config.py`：在 Dreamer 预设之上加一层 `agent.ts.*` 配置，另提供 `small` 预设用于 CPU 工程检查。

### Gym：`research/ts_v1_account.py`
- `account_native(env)`：10 维账户事实，包括 TP/SL 距离、浮动点数、持有分钟、reward scorer 的 `bars_seen`、`adverse10_fired` 和跨交易日数（A2/R02）。
- `StudentEnv` 包装器把这一项加入 obs。
- 与计划的偏差：原计划直接改 `entry_env` 的 obs 契约，实际改为包装器。原因是旧 corpus、旧测试和旧 obs space 无需改动，金融逻辑零改动。
- 旧 corpus 没有 `account_native`，训练时以 `account_valid=0` 标记该字段不可用，不伪造数值。

## 已知事项
- `opt` 的 warmup 设置使第 1 次更新的 lr 为 0。这是配置所致，不是 bug。
- 当前 L_account 是保留事实的自编码式辅助项，只足以满足 R17“账户编码不是随机常数”；更强的账户目标可以在 L6 再加。
- 从 F1 继承的 RSSM 原先接收 one-hot 动作，现在固定接收零向量，存在轻微分布偏移，需要靠 L1 继续训练消化。
