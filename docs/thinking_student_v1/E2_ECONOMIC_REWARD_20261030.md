## 解读

1. **起作用的是折扣，不是奖励单位。**
   - R1 只把奖励换成净盈亏、保留每分钟折扣，结果与 R0 几乎完全相同。
   - R2 去掉 H 内的折扣后，净 PnL 改善 18,417（随机标准差的 5.8 倍），SL 从 53 降到 41，最大回撤从 37,170 降到 21,534。
   - 这印证了 e1.md 风险 1：每分钟折扣让较晚的 SL 被大幅少罚，Q 因此系统性高估 ADD。
2. **R2 不是"学会不交易"。**
   - ADD 只减少 10%（273 → 246），TP 率从 80.2% 升到 83.3%，对同频随机账户从 −5,269 变成 +5,933。
   - Anchor 翻转主要是 ADD → WAIT（2,975 次），说明 Q 的"刹车"有了经济依据，并且有选择地踩。
3. **要准确看待幅度。**
   - 正式第 7 轮（R0）把 π₆ 的 DEV −15,918 退化到 −35,145。R2 版本 −16,728，回到了 π₆ 的水平。
   - 也就是说，这一轮 R2 主要避免了 R0 目标造成的退化，还没有超过 π₆。
   - 是否会随轮次继续改善，需要后续轮次验证。
4. **局限：**
   - 只有一轮、一个训练种子、302 个 CF 配对。
   - DEV 只有一个合约，并且已用于选型和 E0/E1 分析，所以这是方向诊断，不是泛化结论。
   - PAPER 和 FG701 live 未参与判定。
