## S5-1：B1 教学题（新模块 `thinking_student/feedback.py`）

CLI 写法与 `exam.py` 相同，编排器通过 `_call('feedback', ...)` 调用。

**输入：** 冻结 π_k 的一份完整 collection、该合约的 TRAIN 教材、同一 π_k 的 CF（可以缺）。

**一道题 = 一个决策行。** 记录：
- π_k、合约、cursor 和时间；
- 答卷，以及 `proposed` / `executed` / μ；
- 该行是否空仓、资金不低于下限且可以 ADD。

**每类反馈都带 source、ready_at（cursor）和 valid：**

| source | 所在行 | 内容 | ready_at |
| --- | --- | --- | --- |
| TEACHER_ADD_FACT | 空仓、资金够、可 ADD | 事件与时间箱、early10、MAE、quality；复用 `labels.outcome_labels` | `facts.observed_until` |
| STUDENT_EXECUTED_NATIVE | 学生执行了 ADD | 实际出场、原因、pnl（来自 attributions） | 出场 cursor；到 collection 结束仍持仓的，算未到期 |
| VERIFIED_CF_NATIVE | 分叉行 | status、G_ADD、G_WAIT、ΔG | `coupled_at`；TERMINAL 取合约末行；NOT_COMPARABLE 弃权 |
| HINDSIGHT_ORACLE_TEACHING | 空仓、资金够 | strict 示范（有效且不平局） | 合约末行（要用整段后缀） |

**错题标记（阈值放在配置里）：**
- **后果错（F2）：** 答卷给实际结果的概率低于 `outcome_error_prob`（默认 0.2）。实际结果指 H 内的 TP、SL、OTHER，或 H 之后仍持仓。在 H 之前被截断的弃权。
- **决策错（价值 / Actor）：** CF 有效，且执行的动作比另一个动作差超过 `decision_error_margin × κ_Q`（κ_Q 取同轮合并值）。如果 strict 示范与 CF 认为较优的动作一致，另记 `teachers_agree`。
- **偶然差异：** 无法逐条区分。只用补课比例上限来限制它的影响，不声称能分出噪声。
- **市场 / 表征错（F1）：** V1 的 L6 不训练 L1，所以不打这一类标记。

**放行规则 `release(items, order)`：**
- OFFLINE_TRAIN：放行所有已算出且有效的反馈。教师使用的是 TRAIN 的完整后缀，这是合法的已知事实。
- ready_at 照样逐条保存，留给以后的时间顺序实习使用，现在不参与放行。
- TIME_ORDERED：直接拒绝，报 `TIME_ORDERED_NOT_SUPPORTED`，不提供部分实现。
- 只接受 TRAIN 教材，沿用 `corpus_sources` 的 fold 检查；DEV 和 TEST 不会进入。
- `items.npz` 和 `summary.json` 写明 `teaching_order: OFFLINE_TRAIN` 和 `time_ordered: TIME_ORDERED_NOT_SUPPORTED`。

**输出：**
- `experience/<π_k>/feedback/<合约>/items.npz`：按决策行存列。
- `summary.json`：各来源的题数、到期数、弃权数、错题数，以及唯一 cursor 数。
- 原子写入，已存在就跳过；只用 CPU，秒级完成。

**先在真实数据上试：** 用第 1 轮已有的 `pi_0000` collect + CF（FG001/FG005/FG009）建题，看后果错和决策错各有多少，据此确定两个阈值的默认值。

## S5-2：B2 课程：自然覆盖 + 有上限的补课

- **语料窗口：** `CorpusWindows` / `MultiCorpusWindows` 新增 `remedial=(cursors, fraction)`。
  - 每个 batch 中有 `round(fraction × B)` 个窗口，从覆盖错题 cursor 的起点中抽，保证窗口包含该行；其余窗口照旧按自然权重抽。
  - 补课窗口仍来自 LABEL_ACCOUNT，标签与自然窗口完全相同。
  - L2 复习用后果错的 cursor，L5 用 `teachers_agree` 的决策错 cursor。
- **Q 窗口：** `QWindows` 新增 `remedial_boost`。决策错的 CF 行在起点权重里再乘这个系数，其余行不变。
- **报告：** 分开记三种计数：唯一市场 cursor、补课曝光、优化器曝光，并记录补课在 batch 中的实际占比。补课是重复曝光，不算新的市场样本（EDU-R10）。

## S5-3：L6 接入 `formal_train iterate`

**开关：** 配置块 `iteration.l6`，默认关闭，关闭时行为与现在完全相同。字段：
- `from_round`、`outcome_review_updates`、`remedial_fraction`、`remedial_boost`；
- `outcome_error_prob`、`decision_error_margin`；
- `order: OFFLINE_TRAIN`。只接受这一个值；写 TIME_ORDERED 时 `load_config` 报 `TIME_ORDERED_NOT_SUPPORTED` 并拒绝。

**开启 L6 的一轮：**
1. collect → check → CF。
2. **feedback（B1）。**
3. **L2 复习：** `train-outcome`，自然窗口 + 后果错补课。放在 L4 之前，让 Q 和先验刷新去适应它。
4. L4，带 Q 补课。
5. L5，带示范补课。
6. freeze π_{k+1}，然后 DEV 考试。

**参数边界：**
- L2 复习只更新 A6 中 L2 允许的参数组：outcome，`l2_fusion` 为真时含 fusion。
- 它不碰市场脑，所以 MarketCarry 存储仍然是部署时的市场记忆。
- L6 不训练 L1；需要刷新市场脑时，另开 run 并重建存储。

**记录与续跑：**
- `run_state` 每轮记：
  - `L6: S5_FEEDBACK_CURRICULUM` 或 `L6_SKIPPED_BY_CONFIG`；
  - 反馈摘要、补课曝光、L2 复习的更新数。
- 每轮记录和 freeze 的 lineage 都写入用到的 feedback 目录、`teaching_order: OFFLINE_TRAIN` 和 `time_ordered: TIME_ORDERED_NOT_SUPPORTED`。
- 训练报告和文档都写明：这是离线 TRAIN 教学，不是严格时间顺序的在线学习。
- 续跑时 feedback 已存在就跳过；L2 复习的剩余次数按 learner 的 progress 计算。

**CLI：** `run.py` 的 `train-outcome` / `train-policy` / `train-value` 增加 `--feedback DIR`（可重复）、`--remedial-fraction` 和 `--remedial-boost`。不给这些参数时，行为与现在完全相同。

## 实现中的调整（数据依据）

- **后果错阈值默认 0.1，不是 0.2。** 第 1 轮 `pi_0000`（FG001/FG005/FG009，18,502 道有实际结果的题）：低于 0.2 时 1,271 道错题里 1,011 道是 SL，SL 事实几乎全部被标为错（1,011/1,185），补课就变成了按类别重采样；低于 0.1 时是 398 道（SL 266、OPEN_AT_H 96、FG005 的 TP 36）。
- **决策错阈值默认 1.0 × κ_Q。** 同一轮 614 对 CF，合并 κ_Q = 0.559：差距超过 κ_Q 的执行动作有 101 个；其中 ADD 30 个，strict 认同其中 29 个（进入 L5 示范补课）；WAIT 71 个，strict 认同 5 个（主要进入 L4 补课）。
- **κ_Q 从 CF 的 targets 直接计算**（`value.cf_kappa`，与 `MultiQWindows.kappa` 共用 `pooled_kappa`），不为算 κ 加载整份回放。
- **L6 与预算 CF（用户 2026-10-24 方案 3 之后）：**
  - 预算 CF 没有模拟的分叉记为 UNAVAILABLE_BUDGET，与 NOT_COMPARABLE 一样弃权。
  - 教学题 summary 把两者分开计数（`abstained.cf_not_comparable`、`abstained.cf_unavailable_budget`），并记录 `cf_coverage`。
  - 某轮有合约的有效对覆盖率低于 `cf_min_coverage` 时：
    - 跳过 L4，π_{k+1} 保留 π_k 的价值脑和锚；
    - L5 也不接这份 CF 产生的决策错补课，记为 `decision_remediation: SKIPPED_CF_NOT_REPRESENTATIVE`；
    - L2 复习只用事实的后果错，与 CF 无关，照常进行。
