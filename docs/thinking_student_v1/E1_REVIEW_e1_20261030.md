# E0报告Review：现在可以确定下一步方向了

我基本同意E0的优先级：下一轮先研究Reward与经济目标的对齐，不要继续扩大10x训练，也不急着修改Outcome、Q和Actor的网络结构。

但报告中有三个结论，我认为需要修正：

1. Reward与真实盈亏存在系统性冲突——证据很充分。
2. 当前输入下没有可泛化信号——证据支持“尚未发现稳定信号”，但不能证明信息不存在。
3. 只修改Reward就能让学生正确选择WAIT——这是待验证的假设，不是已经得到保证的结果。

这三个区别很重要，因为Thinking Student是探索性项目。我们既要改善学生的学习方向，也要防止它学到一种最简单但没有研究价值的行为：永远WAIT。

## 一、E0最重要的发现：学生确实在追求一个偏离经济目标的Reward

TRAIN上不同目标隐含的盈亏平衡TP胜率

0%25%50%75%100%折扣交易Reward原始Quality Reward真实净盈亏

这三个数字已经解释了此前大部分现象。

| 指标             | TP均值   | SL均值    | 盈亏平衡TP率 |
| -------------- | ------ | ------- | ------- |
| Quality Reward | +0.729 | −3.092  | 80.9%   |
| 折扣后的单笔Reward   | +0.578 | −1.632  | 73.8%   |
| Native净盈亏      | +282元  | −1,823元 | 86.6%   |

而1x和10x在模拟盘上的实际TP胜率都是约82%。

因此可以同时出现：

- 学生的累计Reward为正。
- 学生的人民币净盈亏为负。
- 进一步增加训练投入，并没有提高真实经济表现。

这不是数学矛盾，而是优化目标不同。

尤其需要关注第二行：折扣进一步降低了未来SL的惩罚权重。这是当前Q学习目标与经济收益偏离的重要来源。

不过需要准确区分：73.8%是报告按首笔交易折扣回报推导的门槛，不是完整策略条件\\(\Delta Q\\)的统一盈亏平衡门槛。完整Q还涉及WAIT之后的其他交易。

结论：调整Reward有充分理由，但仅调整TP/SL奖惩比例还不一定能彻底对齐Q。

## 二、Outcome诊断：能够证明什么，不能证明什么？

样本外SL30风险识别能力（AUC）

| 模型          | DEV   | PAPER合并 |
| ----------- | ----- | ------- |
| 1x Outcome  | 0.392 | 0.513   |
| 10x Outcome | 0.540 | 0.533   |
| 独立梯度提升模型    | 0.522 | 0.524   |

AUC=0.5表示排序近似随机；PAPER已经曝光，应当作为探索诊断而非新的独立验证集。

这组结果确实让人失望，尤其10x在TRAIN上达到0.99，在PAPER却只有0.533。

我认为可以确认：

现有Outcome没有学到稳定、可迁移的SL30风险排序能力。

但报告进一步认为“问题不在Outcome结构和训练方式，而是市场输入里没有信号”，这个推断过强。

原因有两点：

- 独立探针只使用20个手工构造特征，不能代表完整的行情序列、Market Brain表示以及可能存在的非线性交互。
- 按合约留出的AUC接近0.5，证明的是当前探针没有稳定泛化，而不是所有可能的入场前信息都无法预测结果。

不过，这不足以支持现在继续扩大Outcome网络。我同意本阶段暂时冻结它。

另外，报告指出实际入场的SL率低于全部候选：

| PAPER | 全部合法候选SL率 | 学生实际SL率 |
| ----- | --------- | ------- |
| 1x    | 22.1%     | 18.0%   |
| 10x   | 20.2%     | 17.9%   |

这说明学生的选择行为可能已有一定效果，不能因单个`p_sl_h`的AUC接近0.5，就否定整个Actor的择时能力。不同候选集合和动态仓位占用也会影响这个对比。

## 三、Q诊断：现在有证据证明它不是可靠的决策依据

E0提供了比此前更有说服力的数据：

| 指标                    | 1x    | 10x   |
| --------------------- | ----- | ----- |
| ΔQ/ΔG平均Spearman       | 0.006 | 0.458 |
| 符号一致率                 | 48.1% | 72.7% |
| 多数符号基线                | 56.8% | 77.1% |
| EXACT_STATE分支Spearman | 0.015 | 0.066 |
| Q引起翻转后符合ΔG方向的比例       | 41.2% | 45.1% |

10x表面上的Spearman 0.458很容易令人误以为Q已经学会。

但按分支拆开以后，相关性主要来自特定的WAIT→ADD、`FUNDS_SAFE`样本；在`EXACT_STATE`和学生原本ADD的分支上，相关性仍接近0。

而且，两组符号预测都没有超过各自的多数类别基线。

我的判断：现有Q尚不能作为可靠的自主价值判断。

这里我也要修正报告中的一处推断：41.2%的翻转方向正确率，不足以单独证明Q降低了累计回报。因为正确翻转与错误翻转造成的\\(\Delta G\\)幅度可能不同。

应该计算：

\\[ \text{Q翻转的平均价值增量} =\operatorname{mean}(G\_{\text{实际选择}}-G\_{\text{关闭Anchor的选择}}) \\]

并且做一次关闭Anchor后的完整Native闭环运行，观察后续账户状态变化。

这个实验成本低，应该优先完成。

## 四、我不同意立刻把“经济Reward”作为正式替代方案

我同意优先研究它，但需要注意两个重要风险。

### 风险1：只改Reward、不改折扣，仍然不能完全对齐人民币盈亏

如果把SL奖励改成对应真实亏损的数值，却仍使用\\(\gamma=332/333\\)，较晚发生的止损依然会被折扣。

这时Value Brain学习的仍是：

\\[ Q^\pi=\mathbb E\left[\sum_t\gamma^t r\_{\text{economic},t}\right] \\]

而不是无折扣的累计净盈亏。

所以至少应在研究中区分：

- R0： 当前Quality Reward，作为原始对照。
- R1： 按真实净盈亏进行归一化，但保留当前折扣。
- R2： 按真实净盈亏归一化，使用无折扣或经过严格经济解释的时间偏好。

R1与R2不应该同时修改后只与R0比较，否则无法判断收益变化来自Reward还是折扣。

不需要把这三个方案都跑完整10x。先利用已有Native交易轨迹核对它们的数学性质，再进行小规模训练。

### 风险2：Reward对齐以后，学生可能学会永远WAIT

这是我认为最需要提前认识到的结果。

在当前数据缺乏稳定预测信号、随机交易又普遍亏损的情况下，假设经济Reward完全正确，那么：

永远WAIT获得零净盈亏，确实可能比持续交易更好。

从资金保护角度，这是一种合理决策；从Thinking Student探索项目角度，它又不能证明学生已经学会了区分好机会和坏机会。

因此，我建议把两个目标分开：

交易策略层面： 允许学生WAIT，不能为了制造交易次数强迫ADD。

学习探索层面： 即使学生选择WAIT，仍应通过老师示范、Native事实和反事实数据持续提供可学习的ADD后果。

这样既不强迫模型承担负期望交易，也不会因为它暂时选择WAIT就让整个学习循环失去数据。

## 五、我的最终探索顺序

我建议将E0之后的工作压缩成两个实验，不新增复杂的Gate体系。

E1：冻结学生，隔离Q的决策影响

在1x π₆、10x π₄上对比`β_Q=1`和`β_Q=0`，先用DEV完成。

记录真实交易次数、TP/SL、净PnL、Reward，以及原策略中Q翻转位置对应的真实CF价值差。注意`β_Q=0`只关闭显式Anchor，并不会移除Reasoning/Gate中的Q上下文。

目的： 判断Q现在是在帮助决策，还是应该暂时降低其投票权。

E2：经济目标对齐的最小训练实验

在独立分支维持TP5/SL30、网络结构、训练数据和小规模训练预算不变，优先比较原Quality Reward与归一化净PnL目标。

必须同时检查折扣的影响。若经济Reward改变，原来的CF回报和Value监督也需要按新定义重新计算或可靠地重新标注，不能直接沿用旧`ΔG`。

观察模型能否在不依赖新的风险规则下减少负价值ADD，同时保持学生完整的收集、教学、学习和发布流程。

E2的结果可以这样解释：

| 观察结果                    | 意义                      | 后续方向             |
| ----------------------- | ----------------------- | ---------------- |
| 净亏损减少、交易次数适度减少、仍有选择性ADD | 经济目标改善了决策               | 保留架构，继续研究Q       |
| 接近全部WAIT，净亏损趋近0         | 学会规避负期望，但没有形成有效择时       | 保留自主探索数据，研究新信息来源 |
| 仍然频繁ADD且亏损              | 仅目标对齐不够，可能是价值学习或决策融合的问题 | 再查Q、Actor与训练效率   |
| 训练效果很好，DEV仍然很差          | 可能存在泛化瓶颈                | 研究市场表示与跨合约稳定性    |

需要保留一个实验纪律：当前DEV已经用于选择π₆、π₄，也已经被多次分析，所以新目标的最终效果必须用之后独立保留的数据检验，不能仅凭DEV改善宣布泛化成功。

## 六、我对E0的最终判断

| E0结论           | 我的Review             |
| -------------- | -------------------- |
| Reward与经济目标不一致 | 确认，当前最值得优先研究的问题      |
| Outcome样本外表现很弱 | 确认                   |
| 当前行情输入不含可泛化信息  | 尚不能证明，只能说现有实验没找到稳定信息 |
| Q没有形成可靠价值预测    | 基本确认                 |
| Q有害            | 证据支持怀疑，需E1直接验证累计影响   |
| 只改Reward就能解决问题 | 不能保证                 |
| 不需要继续扩大10x     | 同意                   |

我的建议是先执行E1，再进行E2的小规模经济Reward实验。 两者都不需要推翻A1–A6，也不需要重新开发整个训练系统。

我们已经通过E0找到了一个非常实质的问题：学生可能正在较认真地优化一个不够符合经济目标的评分体系。

接下来值得检验的是：当评分体系真正考虑交易成本和30点止损的经济代价后，它究竟会学会选择更好的入场机会，还是首先学会不交易。

这两种结果对探索项目都很有价值，但代表完全不同的下一步研究方向。
