# Thinking Student V2：高质量反弹做空正向教材 — Claude 开发任务 V0.3

**状态：设计规范，待开发；2026-10-31。** 本版取代《V0.2 多入场点教材开发规范》中有关“失败样本教材、错误交易类型覆盖、按错误类型展示案例和强制正反例平衡”的要求。如冲突以 V0.3 为准。

## 0. 核心目标

**只生成正确、优质、能够作为老师示范的入场教材。** 不需要制作大批错误入场、失败交易和 BAD/POOR 案例来教学生。我们要教会学生：**外部已给定做空方向 → 等待价格反弹接近已知的 15 分钟前高 → 首次异常放量激活机会 → 在放量后多个合格高位点位中选择入场 → 严格小止损并争取较高盈亏比。**

教材输出只包含：
1. **正向 WAIT→ADD 示范序列**：WAIT 是正确的等待行为，不是“失败案例”。只保留与优质入场相关的必要前置时序，避免无意义的海量WAIT分钟。
2. **一个事件内多个优质 ADD 点**：首次放量只是机会激活，后续量比下降也可有多个合理入场点，不能仅保留一个“事后最高价”。
3. **优质入场说明**：每个点解释为什么位置合格、与前高的距离、触发后的量能背景、结构止损、计划风险与目标盈亏比。

**教师正例库**与**原始研究事实/质检记录**分开：所有事件、候选及真实交易事实可以在离线中间结果中用于可追溯验证，但**不作为错误案例教材，不要求 BAD/POOR、失败事件图集或负样本平衡**。不能伪造市场历史，也不能把所有事后获利点都自动当成优质入场。

本轮只做教材生成与人工Review；**不训练学生、不改生产 Env/Outcome/Value/Actor/Reward、不启动完整1x**，旧V1结果只读。

## 1. 暂定交易规则（用于教材生成与核验，均可配置）

| 项目 | 定义 |
|---|---|
| 方向 | 外部在决策时已经给出 `SHORT_ONLY`；不由未来价格回头决定方向。如果没有真实历史方向信号，只能标为 `DIRECTION_ASSUMED`，不可宣称已验证独立交易收益。 |
| 前高 H | 仅用**当时已经收盘、已经确认**的15m K线构造。实现一个简明的因果算法，不开发箱体识别；事件激活后冻结 H。 |
| 触发 | 接近 H 时首次出现1m量比 `RV≥2`；1m版在该分钟收盘后确认，下一可执行时刻成交。若用户真实使用逐笔即时放量，需真实逐笔数据，不能以1m高点冒充成交。 |
| 后续候选 | 首次放量后事件未失效、价格仍位于上沿候选区、风险合格的多个时刻；**不要求持续RV≥2**。候选区起点可取 `H−5 ≤ 入场可执行价 ≤ H`。 |
| 止损 | 暂设结构失效止损 `SL=H+5`，计划风险 `0<R=SL−实际入场价≤10`；滑点另行记载。 |
| 目标 | 主教材研究目标 `TP=入场价−2R`；并行记录1.5R作分析，不事后按表现任意切换。 |
| 仓位 | 固定3手、单仓位；同一个事件多候选是**不同可替代的入场方案**，不能把它们的收益累加。 |

**重要区分：** 此处的“放量”表示**候选事件开始**，不等于所有随后可入场分钟都要重复出现2倍量；“前高附近”是位置条件，“优质正例”还须通过事先定义的入场质量规则与真实成交核验。

## 2. 正向教材生成流程

### 2.1 从真实TRAIN数据提取机会

1. 审查两仓 `AGENTS.md`、已有15m聚合、1m数据、Native成交/手续费、已有教材入口，写 `ENTRYPOINT_AUDIT.md`；复用真实权威配置，避免新平台和硬编码路径。
2. 使用当时可获得的15m前高、位置和2倍量阈值定位事件，记录 `event_id/H/触发bar/首次可执行时刻/方向来源`。
3. 每个事件保存完整离线候选事实；事件内按时序列举多个可以实际下单的候选。若价格已经远离H或超过风险上限，不得为了凑正例强行纳入。
4. 只用严格因果的价格和成交量信息生成候选；未来行情**只用于离线筛选老师正例和事后质量评价**，绝不能用于在线特征或决定信号时间。

### 2.2 只筛选高质量正例，不制造错误示范

正例必须同时满足：

- **形态与位置真实合格**：在已知空头方向的反弹中，首次放量已发生，实际成交仍位于已冻结前高附近。
- **风险与收益结构合理**：结构止损有效、计划风险≤10点、2R目标价格与费用可复算。
- **成交可信**：不使用同根1m的未来最高价；无不可判定的时间先后、数据缺口或虚假成交。
- **结果用于审核，不冒充实时知识**：优先保留在既定2R规则下确实达到TP且具备可接受MAE/持仓质量的历史入场；未达到条件或无法判断的候选**不进入教师正例库**，但在原始审计数据里保留来源记录，禁止改写成成功交易。
- **一个机会保留多个正确点**：如果同一事件有A/B/C三个都符合上述质量条件，全部可入库；分级只比较执行质量，不把其中两个强行判错。应记录候选间时差、卖出价差、风险R、净收益/净R、MAE与时间。

教师正例等级首版只使用 **EXCELLENT / GOOD**，或者 `POSITIVE` 加连续质量分；**不生成 BAD/POOR 错误教材**。只有实际证据充分才能贴优秀标签；样本不足就如实报告不足，不降低标准凑数量。

### 2.3 WAIT教学：展示“正确等待”，不堆积错误交易

每个优秀事件可配一段**最短必要的因果教学过程**：

`价格远离前高（WAIT） → 反弹接近前高但未放量（WAIT） → 首次2倍放量（机会激活） → 后续A/B/C多个优质ADD候选`。

若实际事件中只有A/C优质，也不要把B虚构为成功或强制给BAD；允许事件中出现候选但不入正例库。WAIT用于说明**何时尚未满足正向条件**，不是训练“错误例子大全”。不必为每根无关分钟建立负教材等级。

### 2.4 防止事后选点的关键限制

- **正例筛选可以使用未来结果作为离线监督，但绝不能隐瞒选择偏差**：入库正例的高TP率是按结果筛选后的统计，**不能声称规则策略本身具备该胜率或盈利能力**。
- 保留所有原始触发事件的总数量、有效候选数量、最终入库数量和剔除原因计数，供人工审核；这些仅是质量控制记录，不输出为负例教材。
- 不允许使用“事后某根K线是最高点”直接反推前高H或放量触发时间；也不能用未来价格决定候选什么时候出现。
- **如果所有候选都长得一样，学生仍可能学不到区别**：在正例内部保留不同时间、价格、量比、风险、执行质量的多样性，不凭高价单一排序。

## 3. 要交付的内容

1. `positive_events`：有至少一个优质正例的事件，包含已知H、量比触发、方向来源。
2. `positive_entries`：事件内多个优质ADD的真实入场价、时间、风险R、止损、2R目标、净PnL、净R、MAE/MFE、持仓时间及分级理由。
3. `positive_timeline`：每个事件简洁的WAIT→放量激活→多个优秀候选时间线；只输出必要的正向教学过程。
4. `audit_summary`：全部原始触发数、候选数、过滤数、正例数；无须提交大量失败交易个案。
5. `figures/`：优先输出**12个真实优质事件**（不足则输出全部，绝不凑数），包含多个合理入场点的可读行情图；图中标注已知前高、首次放量、候选、结构止损、目标及真实成交时钟。
6. `REPORT.md`：正例库总量、跨合约覆盖、每事件正例数量分布、候选质量、因果/执行Review结果、数据来源、限制、能否作为老师示范的结论。**不需要负例图集和错误交易教材。**

数据合同应优先兼容现有Corpus/Reader。原始审计事实和训练正例必须以独立文件/字段或明确的资格掩码区分，确保后续训练Reader**只消费正向教材**。

## 4. 必须通过的Review与测试

- 15m前高及2倍量信号严格因果；1m收盘确认，不得使用当分钟最高点冒充成交。
- 首次放量后仍可出现多个高质量候选，后续无需再次量比≥2。
- 每个入库候选满足真实可执行、风险≤10点、同一冻结H、2R核算与费用正确。
- 一个事件的多个候选是替代方案，不能累计为可实现的交易收益。
- 正例只包含高质量、证据充足的入场；剔除记录仅用于审计，不变成BAD/POOR教材。
- 至少一例真实历史多正例事件（若数据没有，报告缺失），生成可人工Review的价格与量能图。
- 教材中任何当时可见特征不允许包含未来价格、未来净PnL、事后最高点或老师等级；未来结果只能在离线标签列。
- 当前轮仅用认证TRAIN，旧V1只读；DEV/TEST不用于挑选正例；不启动学生训练。

## 5. Claude的执行顺序和停止点

1. 只读审查现有实现/数据及约束；写 `ENTRYPOINT_AUDIT.md`。
2. 写最小 `DESIGN.md`，说明因果前高、RV、事件生命周期、候选时间、正例筛选标准、数据合同。
3. 在一段真实TRAIN历史上生成事件与优质正例，先出至少一张真实可读图确认形态。
4. 扩大到可用TRAIN历史，生成所有合格优质教材、必要的正向WAIT过程和简洁质量汇总。
5. 自动测试并自Review，交付正例数据、图、`REPORT.md`、复现脚本、参数/Git身份。
6. **停止**。不修改生产老师、不接入L3/L5、不训练1x，等待用户亲自看真实正例后再决定。

## 6. 交付前人工自Review（必须明确回答）

- [ ] 教材里是否全部为我们希望学生模仿的高位反弹做空，而非下沿突破追空？
- [ ] 每个示范是否确实发生在放量激活之后？后续点是否可在量比低于2时继续作为优质入场？
- [ ] 是否有一个事件中的多个**正确**入场点，而非只保留唯一的事后最高点？
- [ ] 是否教学生在尚未满足条件时正确WAIT，而不是堆积无关负例？
- [ ] 是否把失败候选只留在原始审计、不纳入老师正例，不为凑量降低标准？
- [ ] 是否明确解释“历史正例筛选成功”不等于“可执行策略已验证有优势”？
- [ ] 是否完成成交时钟、止损风险、成本、未来泄漏和数据身份检查？

**最终原则：教材只教正确的反弹高位放量做空入场；研究底账保持真实完整，但不把大量错误交易制成教材。**
