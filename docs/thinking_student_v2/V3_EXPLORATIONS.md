### B. 波谷阶梯止损（2026-11-07，G-40）

- **用户：** "3-4个波谷， 2个波谷止损 / 5-6个波谷， 3个波谷止损 / 7-10个波谷， 5个波谷止损 / n>11个波谷， n/2个波谷止损"，"都是倒数"。
- **改动：** 3 个及以上波谷时，止损位置按阶梯取：3–4 个用倒数第 2 个，5–6 用倒数第 3 个，7–11 用倒数第 5 个，≥12 用倒数第 n/2 个。V3 原来一律是倒数第 2 个。
- **结果：** 比 V3 多 +130 ~ +490。笔数、胜率、持仓时间、各阶段出场几乎不变：每个品种约 550 笔里只有 63–68 笔走到波谷阶段，走出 5 个以上波谷的更少。
- **结论：** 差别在噪声内，没有采用。
- **位置：** 分支 `paper/ts-v3-trough-ladder-20261107`（gym `40a2b1f`，`exit_rule.trough_ladder`）；paper `PAPER_V3_LADDER_20261107`（review r0014 / r0015）。第一次按正着数实现的 paper 已停，结果在 `PAPER_V3_LADDER_20261107/stopped_from_first_20261107`。

## 5. 小结

- **区间：** FG [H−5, H+2]、SA [H−5, H] 加 V2.4 策略仍是最好的组合。收窄区间（C、D、E）有时让全 ADD 略好，但学生都变差，重训也补不回来。

- **重训：** 每次重训 DEV 分数都接近 0 或为负，best_dev 的挑选信息量很低。
