## 0. 一句话结论

两周里，学生从"什么都学、什么都不赚"走到第一次在样本外稳定盈利。转折**不在模型**，在三件事：

1. 交易成本改成真实值；
2. 规则决定在哪里交易；
3. 出场尺度换成长线，和方向优势的尺度对齐。

V3 长线出场下，同一套 V2.4 策略（不重训）在 FG paper 上 **+24.8k**，在从没训练过的 SA 上 **+27.3k / +32.8k**，都赢过规则内随机时机和"每个规则位置都 ADD"。

## 2. 各阶段

### 2.1 V1：会思考的学生（10-22 → 10-30）

**目标**（`FG_S3_Thinking_Trading_Student_Verified_Counterfactual_Curriculum_Concept_V1_20261022.md`）：
- 学生先预测，再比较，自己行动，承担模拟账户的后果；
- 老师提供可核验的事实和反事实的相对价值，而不是要求学生 100% 复刻事后 Oracle。

**大脑**（A1–A6，`…Brain_Architecture_A1_A6_Frozen_20261022.md`）：

| 模块 | 内容 |
|---|---|
| Market Brain | 继承 F1 的 RSSM，纯市场 |
| Account | 14 维账户事实 |
| Outcome | 34 类竞争风险，加 MAE / MFE / Quality |
| Value | 策略条件的 Q，同策略 CF 精确回报 |
| Decision | z = anchor + correction，只有 z > 0 且 ADD 合法才 ADD |

**课程（S0–S5，C4）：**
- 训练阶段：L1 市场、L2 Outcome、L3 示范、L4 Q、L5 策略、L6 反馈课程；
- 冻结 π_k，在 DEV FG409 上做 Teacher-free 考试；
- 每轮正式训练都做 11 项核对。

**分档老师（G 系列）：**
- 起因：用户发现严格老师每段行情只有一个 ADD 答案；
- 改为多答案分档示范（止盈时间、回调、有利空间），加 MFE 头和正确集，然后完全重训；
- 结果：DEV 8/10 高于随机；paper −72k ~ −88k，比随机少亏，但仍然大亏。

**诊断（E0–E4、R2）：**
- E0：Reward 和 PnL 的盈亏平衡点不一致；
- E1：Anchor 只在部分策略上有帮助；
- E2：Q 的折扣是问题；
- E3 / R2：净 PnL 作为 Q 目标没有带来稳定增益；
- E4：同策略的 ΔG 在留出合约上不可预测（ρ ≈ +0.05）；
- **结论**：学生在样本外没有选点信息，Q / CF 补不了。

**live（10-30）：** 1x π₆ 在 FG701 做空，只做验证，随后停止。

### 2.3 为何无法盈利（G-25，11-05）

报告：`/data/logdir/fg_single3/thinking_student/WHY_NO_PROFIT_20261105/REPORT.md`。

1. **执行摩擦大于方向优势。**
   - 原 env 的开平各差 1 点，止盈要穿价 1 跳。在随机游走上，每笔天然少 2.3–2.8 点。
   - 外部方向在 5–30 点的出场尺度上只提高 2–4 个百分点的 TP 率，补不上。
2. **样本外没有选点信息**：Outcome、Q、z 的 AUC 都在 0.48–0.52。
3. **教材只覆盖 2.6% 的分钟**：正例按结果事后挑出，规则的输家从来不标 WAIT。
4. **Q / CF 补不了**：anchor 只翻转 0.1–0.7% 的决策。
5. **DEV 只有一个合约**：best_dev 选到的是噪声。
6. **方向可能含事后信息**：24 个合约里有 21 个在给定方向上有利（p ≈ 1.4e-4）。方向是系统里唯一的真实信息，但**只在 ≥ 30 点的尺度上值钱**。

第 6 点后来由 V3 验证：方向的价值要靠长线出场才能拿到。

### 2.4 真实成本（11-05）

- **用户口径**：无滑点；1 手 1 点 20 元；开仓 2.1 元，平仓 2.1 元；止盈保留穿价 1 跳。
- **配置**：沿用 CZCE_FG 成本预设（`markets/costs_fg_real_20261105.yaml`），语料记录它的 sha256。

### 2.5 规则闸门：规则决定在哪里，大脑决定什么时候（V2.3 / V2.4，11-05）

  - 教材只覆盖 2.6% 的分钟；

## 3. 经验

1. **先算清成交和成本，再谈模型。** spread 1 一项就把能赚钱的策略变成大亏。成交规则、成本、止盈怎么判定，都要先用"随机入场"的基准对一遍账。
2. **规则决定在哪里交易，大脑决定什么时候。**
   - 让学生自己从稀疏示范里学出规则，失败了：87% 的入场不在规则位置。
   - 把规则做成 env 的合法动作掩码，合规由结构保证，学生只学时机。
3. **出场尺度要和信息的尺度匹配。** 外部方向只在 ≥ 30 点上有优势，5–10 点的固定出场把它吃掉了；按趋势结构移动止损，才把它拿到手。
4. **训练和 paper 可以不同，而且这样可能更好。**
   - V2.4（训练用成交价 +5，paper 用 H+5）好于 V2.5（两边都用 H+5）；
   - V3 用短线训练的策略做长线 paper，结果更好。
   - 学生学到的是"在规则位置里什么时候进"，这和出场方式在一定程度上可以分开。
5. **一个 DEV 合约选不出好策略。** best_dev 多次不如最后一轮（V2.4、V2.5、SA V3），DEV 选择基本是噪声。
6. **迭代循环（Q / CF / L4–L6）贡献很小。** Q 只翻转 2–5% 的决策，前几轮和后几轮差别不大。目前的收益几乎都来自规则、出场和基础训练（L1–L3）。
7. **每次只改一个变量，各开一个分支。**
   - 典型的单变量对照：V2.2 只换成本、V2.4 只换止损、V3 只换出场；
   - 混在一起（V2.5 同时改材料和止损）就难以解释；
   - 单项测试放在 `paper/…`、`run/…`、`live/…` 分支上，主开发分支只合并用户采纳的结果。
8. **工程保障值得做。** 下面这些让每次结论都能复现、可解释：
   - 新代码按旧规则重新生成，结果逐字节相同；
   - 拐点回放和逐前缀重算一致；
   - Native 逐分钟核对；
   - 闸门合规率小于 1 时直接报错；
   - CF 开始前等 DEV 考试结束；
   - run 自动瘦身。

## 4. 风险与未决问题

- **PAPER 已经被反复看过。** FG501–FG605 先后跑过 10 多个变体，参数和版本的选择都看过它的结果，存在隐性过拟合。V3 的 8 点保本、锁 5 点是用户定的，没有在 PAPER 上搜索过，但"选择 V3"这件事本身用到了 PAPER。
  - 需要一段没看过的数据来确认：封存的 TEST、2026 年的新合约，或者 live。
- **方向的来源。** 方向是外部人工给定的，24 个合约里 21 个有利，很可能含事后信息。V3 的利润高度依赖方向，实盘里方向从哪来是最大的问题。
- **样本量。** 每个品种只有 5 个合约、17 个月，一套训练；SA 的手续费按 FG 算，实际可能更高。
- **RB 不赚。** 规则的点数是为玻璃定的，换品种可能要按价格或波动重新定尺度。
- **live。** V3 还没有 live；FG701 上跑的是 V2.4 + H+5（短线）。
